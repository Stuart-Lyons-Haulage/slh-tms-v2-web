# SLH Hub

The SLH Hub is the SharePoint information layer for customers, sites, drivers, vehicles, trailers, source documents, compliance and claims. Live TMS transactions remain authoritative in the API/SQL layer.

SharePoint site: https://stuartlyonshaulage.sharepoint.com
Hub folder: /Shared Documents/Planning/Transport Operations System/00 SLH Hub

Production Power Automate mailbox intake remains unchanged: it stages orders into the TMS and keeps the Info mailbox as source evidence. SharePoint is not inserted as a live-order approval store.
